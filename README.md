# 크리에이터 허브 공개용

휴대폰, 태블릿, 다른 컴퓨터에서 열 수 있는 공개용 크리에이터 허브입니다.

## 사용 방법

GitHub Pages 주소로 접속해서 사용합니다.

```
https://coffeemania68.github.io/creator-hub-public/
```

## 중요한 점

- 로그인 없이 바로 열립니다.
- 입력한 내용은 각 기기의 브라우저에 저장됩니다.
- PC 원본 크리에이터 허브와 자동 동기화되지는 않습니다.
- 공개용 버전이라 개인 폴더 경로와 개인 지시문은 제거되어 있습니다.
- 명령어 보관함에는 공개해도 되는 기본 지시문만 들어 있습니다.
- 지혜샘 철학/명언 쇼츠와 철학 롱폼 원고 지시문이 포함되어 있습니다.
- 휴대폰과 태블릿에서도 사용할 수 있습니다.

## 데이터 백업

설정 화면에서 JSON 내보내기를 눌러 백업 파일을 저장하세요.

다른 기기로 옮길 때는 새 기기에서 JSON 가져오기를 하면 됩니다.
